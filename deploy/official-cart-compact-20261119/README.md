# 自营持久购物车、紧凑卡片与图片交互

本目录只归档源码构建和合成故障测试工具，不包含生产包、环境快照、真实购物车、订单、付款回执或私有保护清单。

## 功能边界

自营商品使用独立 officialCart 存储和 officialCheckout 多件结算，不把官方公开物料编号作为普通库存编号，不改变普通商户/合作渠道购物车与订单路径。价格、数量约束、库存、归属与运费由服务端重新校验；零库存目录仍可展示，但不能购买。原单件预留与新多件预留共享库存核验，支付/关闭/退款沿既有真实接口扩展，不借用旧模块的发布许可。

前台保留自营首位，卡片最大宽度约1280px，删除重复说明。系统授权图片优先，支持悬浮预览与原大图查看器。加入购物车显示成功提示与种类数，同一购物车页面按自营独立分组，支持数量、选择、删除及多件确认。

## 验证与运行状态

源码、原生模块隔离回归、TypeScript及浏览器合成接口回归已执行；实际发布采用独立哈希许可、原有双锁、全字节比较交换、全部旧资源保护和严格自有恢复。API与前台静态已分别正式核验通过。真实公开页面只读浏览器已验证紧凑卡、悬浮预览、大图关闭与手机布局。

合成浏览器的登录、加购、持久恢复与多件确认响应均为本地模拟；公开页面验收拦截全部非GET请求。未新造生产登录会话、真实购物车、订单、支付二维码或付款，因此这些证据不代表真实付款、退款或完整金融端到端实测。

一次错误健康检查的发布尝试在未启用新购物车前恢复原应用字节，随后经独立审查的零代码写完成器关闭自有失败窗口。正式成功版本使用全新nonce、独立stage和新许可；旧包不得回放。健康检查固定为生产实际3000端口及源码注册的 officialMall.list，且在任何活动写入前先检查原公开服务。

工具中的固定运维路径只用于授权范围内复现；源码归档不构成独立生产发布许可。完整保护输入、独立许可和真实收据仅私有保存。
