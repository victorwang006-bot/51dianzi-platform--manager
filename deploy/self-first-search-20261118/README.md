# 自营商品主搜索首位展示

用户确认主搜索结果直接展示已上架的自营商品并置于普通商户之前，取消“只看51自营”复选框和独立目录跳转条。沿用既有搜索布局与简洁 Demo：橙色自营标签、白底商品卡、蓝色型号、示意图、真实品牌/封装/批次、供应方、阶梯报价、税务口径、MOQ、可售数量及交期。不新增栏目、导航或大横幅；列表和网格都优先展示匹配的自营商品。

## 实际接线

平台 `OfficialMallSearchResults.tsx` 使用既有公开 `officialMall.list`，不复制或重新发布库存。`SearchPage.tsx` 在筛选和物料参数区域之后、原商户结果根节点之前添加同位兄弟组件，传入已提交的 keyword、brand、sort、viewMode 等状态。原普通搜索查询、收费配额、分页、商品卡片、联系方式和购物车回调不变；官方 `publicId` 不转作普通库存 ID。

自营独立列表只接公开允许的型号、品牌、页码和页大小。换型号或品牌同步移除旧卡，迟到请求受围栏控制；刷新中和失败时不展示旧报价，不将未知数值补零或把可售数量当现货。超过首屏容量时按需加载更多，仍在商户列表之前；官方条数不加入原商户总数。排序采用完整型号匹配优先和组内所选排序，未明确数据后置。

卡片只使用已存在的公开平台询价操作，不提供未接入的官方购物车或在线下单；完整报价和公开资料通过原生折叠详情展示。保留旧独立目录 URL 的兼容能力，但正常搜索不需要该 URL 或筛选标志。

## 源绑定静态工具

`packaging/build.mjs` 仅编译新搜索卡片和已有图片路径辅助代码，以原生 React、JSX、tRPC、路由和 skipToken 同一对象桥接，不新增 Provider 或查询客户端。旧官方目录工厂、原生宿主入口、旧自营 UI 和普通商户样式保持原字节。

新搜索模块只允许四处精确字节补丁：新卡片叶子导入、自有目录条与封装分支调整、完整复选框节点删除、实际结果根前的源码投影插槽。所有其他字节以逆向补丁验证，HTML 只更新当前实际 Search 引用。源码范围以真实 TypeScript AST 的 token 原文和去除空白后的完整字节双重校验；独立记录空白差异，不将 token 一致称为全文字节一致。前像固定于明确的旧 Git 提交，不在并行编辑中捕获活动源码作基线。

复现前需要按 `freeze-config.example.json` 提供新鲜捕获的 HTML、实际有效 Search、宿主入口、旧目录、旧 UI 和样式，并核实哈希；由当前源码冻结清单提供批准的输入。工具保留此次安全基线的绝对工作路径和旧提交，下一次交付必须新鲜捕获并审阅对应前像，不可直接回放旧包。

```sh
node packaging/build.mjs packaging/source-freeze.json
node packaging/native-checks.mjs
python3 -m unittest discover -s validation -p test_release.py
```

受影响源码 99 项回归、27 项完整原生搜索接线检查、11 项发布故障测试及 TypeScript 检查通过。另以桌面和手机真实 Chromium 在普通搜索 URL 核验列表和网格的首位自营卡，使用实际公开 GET，不创建生产登录会话或执行非 GET 业务请求；不将旧独立目录能读数据当作主搜索首卡验收。匿名浏览器未调用收费商户搜索，原商户结果与回调由源码及实际原生字节范围验证保留。旧 URL 测试一条既有默认字段期望失败没有越界修改，不能声称整个仓库测试全绿。
