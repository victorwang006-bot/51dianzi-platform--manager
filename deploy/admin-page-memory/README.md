## 已实现的行为

商户列表从第12页进入企业详情，点“返回上一页”恢复进入前的真实列表历史条目、第12页、搜索、负责人、入驻时间筛选、每页条数与企业行位置。列表保留原服务端排序，不增加未经后端支持的排序参数。

分页增加首页、末页、附近五个页码和“跳至指定页”，支持20/50/100条每页。非法跳页提示有效范围，不改变当前页。分页及生效筛选写入网址，刷新后不回第一页；修改筛选或每页条数时主动回第一页。

详情增加“上一家／下一家”，按进入时的筛选和排序连续查看，支持从第12页末企业跨到第13页。连续查看有独立当前页记忆，不覆盖最初来源；即使查看了第13页多家企业，返回仍回进入时第12页。

资料修改后返回强制获取最新列表数据，不缓存企业资料或编辑表单。如果文字变化导致行高变化，以原企业行在屏幕上的锚点保持阅读位置；原记录不再符合筛选时采用原位置回退。只有总页数减少、原页码失效时才收敛最后有效页，不清空其他筛选。

浏览记忆独立于CRM，按后台管理员ID、实际角色和权限集合隔离。身份未就绪不读取旧身份记忆，角色缺失不默认超级管理员；后端原权限验证不变。
