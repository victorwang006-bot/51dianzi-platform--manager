# 后台工作台式导航

## 已批准范围
仅修改 admin.51dianzi.com 左侧导航，沿用用户工作台截图的蓝色分组标题、右侧展开箭头、纯文字缩进菜单、浅蓝整行选中态。分组为：用户与商户（商户管理、用户管理）；交易与服务（订单管理、消息中心、评价管理）；数据与运营（物料数据库、运营数据）；系统管理（后台用户管理、异常日志、个人信息）。原名称、地址、权限、角标和已读处理、预加载、页面状态记忆均不改变；不恢复智捷业务。

## 实现
复用当前实际布局的原菜单项渲染回调（含所有点击/提醒/预加载逻辑），仅将分组外壳替换为一个独立导航组件。组件通过参数接收原权限过滤后的菜单项、当前路由和账号；按账号保存展开状态，直接访问/切换页面自动展开相应组，可同时展开多组、隐藏空组。展开时隐藏子菜单图标，整体缩窄为图标栏时保留原图标和提示保证可导航。默认宽220px，保留原宽度调节和已有保存值；标题14px/子菜单13px/行高40px。顶部Logo与底部账号保留，中间独立滚动并禁止分组被Flex压缩。

## 项目结构
client/src/components/admin/AdminWorkbenchNavigation.tsx 负责分组外壳与展开交互，配套CSS只作用于该导航。纯分组和保存状态工具独立并单测。DashboardLayout.tsx在原SidebarContent内接入并复用既有回调。deploy/admin-workbench-navigation-v1包含实际分片的增量构建、明确指纹门禁、受保护发布及只读回执。

## 发布
从当前线上DashboardLayout分片生成单独内容寻址布局分片和导航运行时/CSS，在最新HTML中只替换其现有布局importmap键并追加一条限定样式链接。完整保留所有其他HTML、模块映射、CSS和商户审核/消息提醒/页面记忆补丁。使用非阻塞共享发布锁、实时指纹保护和精确增量回退；不整体构建覆盖生产主包，不修改API/数据库/Nginx/服务，不重载任何进程。保留智捷退役404、库存上传和清空权限修复等全部其他成果。
