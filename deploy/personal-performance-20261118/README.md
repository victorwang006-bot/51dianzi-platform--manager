# 个人业绩与提成预览接通（2026-11-18）

## 范围

修复后台个人中心到平台统计服务的真实委托读取：内部固定方法登记、销售读取权限、可信员工主体、授权公司选择和完整结果返回。新增个人提成预览，从本人订单保存的历史规则版本、真实批次成本审计、费用和银行/现金回款核验计算，不补造订单、收款、出货、结算或发放记录。

个人业绩按所选北京时间自然月统计本人在当前企业的有效人民币订单，银行/现金回款与账期登记分别展示。订单金额保持各订单原税务口径，不将未税或混合订单误标为全含税，也不进行未授权的税额换算。

提成按所选订单创建月展示，截至当前累计银行/现金回款足额仅表示“回款达标提成预览”。预计、待核、已核小计、完整合计不可核与发放来源不可用分别展示；未知历史规则、缺少成本或分配证据不按零成本推算。未接通可审计发放来源时，发放金额和退款金额保持未知，不冒充工资或已发放提成。

## 安全与前端行为

固定的两个个人统计方法使用真正只读的主体/中间件，保留当前企业、所有者、员工成员、登录状态、ERP资格、销售权限及客户/需求可见范围检查，避免普通CRM认证读取路径的同步写副作用。其他业务方法保持原授权链。

后台在原授权锁内重新核查账号状态、session版本、归档、绑定和公司授权范围；公司选择只返回已有授权的名称和ID，不接受浏览器指定员工、企业所有者、比例或提成金额。失败返回安全分类与关联编号，不透传数据库或上游秘密。

个人资料、所属公司/岗位、头像及原安全操作保留。统计的月份、公司、分页和会话请求隔离；切换中、失败时不展示上一组金额，迟到响应不能恢复旧结果。业绩与提成独立分页，合计直接来自服务端全量统计，不是当前页求和。
