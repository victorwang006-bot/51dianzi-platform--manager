# 后台独立官方商城物料 · 已批准方案

后台是独立信息系统。商城物料只取后台自行新增/导入的官方记录，不使用前台企业库存、员工前台账号、工作台或商户绑定。员工身份与查看/编辑导入/发布权限使用原生后台admin_users及官方权限、官方团队范围；不自动授权不相关账号。现有渠道库存和前台库存均保留，不能自动充当官方自营。前台只消费明确上架后的公共商品投影，私有负责人、团队、导入内容与审计不公开。

设计沿用渠道库存白底、深色正文、紧凑表格、独立品牌列；无冗余标题栏、前台预览及已有库存弹窗。新增物料只提供手工录入、表格导入、粘贴识别；工具栏少量型号/品牌/状态筛选和新增按钮，批量操作仅在选中后显示。行内主动作上架/下架，编辑使用轻量文本入口或点击型号。完整梯度价格在价格单元格展开和表单中成对编辑。

数据模块：后台新增officialMall独立材料、公开发布快照、原请求/操作回执账本；复用现地官方权限和团队安全边界而不更改原渠道表。所有用户写在原生事务中以真实本地会话、当前权限和revision终门核对，原UUID回执支持重放核对，未知结果不得自动创建/上架。前台仅新增公开读取适配，旧购物车/订单/到账路径保持原规则，独立命名空间不混用ID。

表格支持xlsx/csv、Excel多行粘贴及供应商文本；模板包括型号、品牌、封装、批次、可售/实际数量、货期、含税、基础价格、MOQ、包装倍数及成对梯度数量/价格列。解析/匹配列、错误行提示及下载、有效行分批导入进度/结果；重复策略跳过/更新(必须revision)/另建批次，不静默覆盖。联想只来自后台产品资料/官方已录入资料的型号品牌封装，准确/多个候选/未匹配分别提示；数量/价格/货期与税不可猜测，全部人工确认后先保存待上架。

目录：manager/shared/officialMall.ts为共同输入/输出契约；manager/drizzle/officialMallSchema.ts及server/services/officialMall.ts管理原生数据/权限/发布回执；server/routers/officialMall.ts注册本地API；client/src/business/MallMaterials.tsx及导入助手提供简洁页面；front server公开读取与页面适配消费安全投影；当前实施目录复用原字节增量编译/单次原子发布/保护哈希回滚。仅新增必要空表及静态/runtime资源，不填演示商品/联系方式或自动上架、不迁移或删除原业务数据、不更改Nginx/PM2环境，不作真实商品或订单写测。
