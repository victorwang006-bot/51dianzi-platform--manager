# 普通搜索与官方目录入口

后台官方商城物料与普通库存搜索读取不同数据源。本次排查确认已发布的物料能够通过前台官方目录的匿名 list/detail 读取并在实际浏览器显示；不以重复上架、补库存关联或修改价格数量来处理普通搜索的可发现性问题。

最小变更是在普通搜索增加“51自营官方目录”链接，沿用当前提交型号和品牌进入已有独立目录。链接只转发公开搜索条件，清理普通页码、排序、商户、企业、token 等库存上下文。型号包含加号、井号、斜杠及中文时保持正确编码。没有关键词时进入完整官方目录。

原普通商户的查询、卡片设计和交易规则、自营 true 分支、React/trpc 单例、官方目录组件及商户 CSS 均保持不变。没有新增官方商品购物车或在线下单能力，没有 API、数据库、价格库存、许可、worker 或进程更新。

`tools/` 归档源投影、单个搜索模块增量和离线范围回归；`release.py` 仅允许一个内容寻址 SearchPage JS 与前台 HTML 精确映射切换。发布采用双锁/全字节 CAS，保护最新后台页面、其静态资源及全部服务进程环境，异常只回滚自身仍持有的后像。回归与部署用到的生产 bundles、配置、原始响应、真实账号、商品报价数量及私有保护清单不纳入公开仓库。
