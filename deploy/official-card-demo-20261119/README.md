# 官方搜索卡片：最终 Demo 与系统图优先

本目录归档源绑定的最小增量构建和匿名故障回归工具。完整生产 API、静态 bundle、环境配置、原始运营回执、真实订单或导入数据不进入仓库。

## 实现范围

普通搜索保留自营首位与原有商户列表、网格、排序、配额、回调及合作渠道逻辑。新版自营卡片按图像、资料、阶梯价、数量报价、联系五区组织；窄屏换行显示。使用橙色自营标识，真实品牌、封装、批次和库存，不新增演示字样、公开编号、假 QQ、无依据货期或现货承诺。

系统公开图库命中时优先使用系统图；未命中才沿用示意图降级。只读图片投影以完整型号、唯一有效字典行、现有品牌身份匹配和已批准来源为约束，不复用其他商户私有库存图片。上游图片字段先剥除，再由本系统图库附加可选 `thumbnailUrl` 与 `imageKind`，失败不影响公开报价。图片只是目录参考，不是某一批库存的实拍证据。原公有查询输入、角色上下文、价格数量与财务数据不改。

数量与 MOQ、可空 SPQ 以及真实阶梯价联动；空 SPQ 表示未提供包装倍数约束，不能自行当作错误或猜测为其他包装量。小计使用精确十进制展示计算。联系方式复用现有平台客服路由；加购必须同时具备正式就绪标记和真实官方草稿回调，不能调用普通库存购物车或显示假的成功提示。本轮视觉叶子不编译支付对话框，也不启用支付。

## 验证边界

原生候选校验保持原 Search/K1、wrapper、adapter 及其他 imports 完整不变；Search 只有官方叶子 import 一处改变，HTML 为现存实际映射的 13 处值变化。构建闭包显式绑定源、工具、包版本和现有宿主对象，不能引入第二套 React、查询客户端或会话。

候选浏览器使用正式应用宿主、新静态候选与已公开的只读列表快照及真实系统图片原字节进行桌面、窄屏、列表和网格核对；这不是正式上线证据。实际线上页面另外使用正式资源、正式只读 GET 验证，不发交易请求或创建会话。已登录商户的收费搜索不在匿名浏览器测试中模拟，相关旧逻辑靠实际原文字节保留和现有合成回归保护。

## 运维注意

图片 API 和卡片静态资源分独立范围发布。图片 API 只更新原生公开服务的图片依赖和 runtime 导入，静态阶段只增加两份内容寻址 JS 并切换精准 HTML 映射。两阶段均使用项目共享双锁、全字节 CAS、独立许可和严格自有版本恢复，不整包回放其他任务的改动。

PM2 集群滚动会改变进程 PID 和 Node IPC 字段，并重建 `pm2_env` 自动元数据；不得把这些完整原始字节变化误判为用户配置变化。应分别验证原用户配置哈希、实际进程中嵌入的用户配置，以及非目标进程的完整原身份与环境；纯静态发布没有重载，因此所有进程的原始快照必须完全相同。若发布失败，保持原错误记录、只处理仍属自身精确 nonce 和字节前后像的窗口，不重试已禁止回放的旧发布器。
