# 生产部署构建说明（阿里云 ECS 47.97.108.147）

> 2026-07-30 第38轮事故复盘产物。**每次给生产后台打包前必读。**

## 事故回顾

第35轮部署时直接用 `pnpm build`（默认 base="/"）的产物覆盖了生产 `/opt/apps/dianzi51-admin/dist`，导致：

- `index.html` 引用 `/assets/*.js` —— 该路径被 Nginx 转发给前台（3000 端口）返回 HTML，后台页面空白
- 前端 JS 内 tRPC 请求地址为 `/api/trpc`（应为 `/admin/api/trpc`）
- wouter 路由 basename 为 `/`（应为 `/admin/`）

已于第38轮在生产机上就地修复（index.html 与 JS 内共 3 处路径，备份后缀 `.bak.r38`）。

## 正确的生产构建命令

生产后台部署在 Nginx `/admin/` 前缀下，vite.config.ts 已支持 `VITE_BASE_PATH` 环境变量（第 155 行 `base: process.env.VITE_BASE_PATH || "/"`）。

```bash
# 在本地沙箱构建生产后台部署包（注意 VITE_BASE_PATH，尾斜杠必须带）
cd /home/ubuntu/dianzi51-platform
pnpm build:admin
pnpm verify:admin-build
```

构建后自检（三项都必须通过）：

```bash
grep -c '/admin/assets/' dist/public/index.html                 # 应 >= 2
grep -c '"/admin/".replace' dist/public/assets/index-*.js       # 应 = 2（trpc url + 路由 basename）
grep -c '="/".replace' dist/public/assets/index-*.js            # 应 = 0
```

> 注意：前端代码中 trpc url 与 wouter basename 均来自 `import.meta.env.BASE_URL`，由 Vite 在构建期注入，无需改代码。

当前仓库同时提供 `deploy/nginx/dianzi51-admin.inc.example` 与 `deploy/ecosystem.config.example.cjs`。前者通过带尾斜杠的 `proxy_pass` 将 `/admin/` 前缀移除后转发至 3001 端口，后者仅引用服务器进程环境中的凭证，不在代码仓库保存生产秘密。

| 生产变量 | 用途 | 要求 |
|---|---|---|
| `DATABASE_URL` | 后台 RDS 连接 | 必填，生产密钥 |
| `JWT_SECRET` | 后台登录会话签名 | 必填，生产密钥 |
| `PORTAL_API_KEY` | 前台对接接口鉴权 | 前后台对接启用时必填 |
| `UPLOAD_DIR` | 物料图片磁盘目录 | 建议 `/opt/apps/dianzi51-admin/uploads` |
| `PLATFORM_DB_NAME` | 前台跨库库名 | 默认 `dianzi51` |
| `SMS_*` | 阿里云短信找回密码 | 启用短信渠道时必填 |

## 上传与重启

```bash
# 打包（dist + drizzle）上传，先备份生产旧 dist
tar czf /tmp/admin-dist.tgz dist drizzle
scp -i /tmp/ecs_key.pem /tmp/admin-dist.tgz root@47.97.108.147:/tmp/
ssh -i /tmp/ecs_key.pem root@47.97.108.147 '
  cd /opt/apps/dianzi51-admin &&
  cp -r dist dist.bak.$(date +%m%d%H%M) &&
  tar xzf /tmp/admin-dist.tgz &&
  pm2 restart dianzi51-admin --update-env'
```

## 部署后验证

```bash
curl -s http://127.0.0.1/admin/ | grep -o 'src="[^"]*"'          # 资源应为 /admin/assets/
curl -s -o /dev/null -w '%{http_code}\n' \
  "http://127.0.0.1/admin/api/trpc/auth.me?input=%7B%22json%22%3Anull%7D"   # 应 200
```

浏览器打开 http://47.97.108.147/admin/ 应看到登录页。

## 其他注意事项

- 生产 ECS 上前台（dianzi51，端口 3000）与后台（dianzi51-admin）各自独立目录，Nginx 按 `/admin/` 前缀分流；后台静态资源必须落在 `/admin/assets/` 路径下
- 数据库迁移：生产 RDS sql_mode 严格，`timestamp` 列需显式 `NULL DEFAULT NULL`
- 生产机源码目录（如有）与 dist 可能不同步，重建前先核对
