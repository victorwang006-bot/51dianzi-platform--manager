## 六、回滚方法

若需要快速回退运行版本，可在 ECS 以 root 执行以下命令。该流程会产生短暂停机，但会同时恢复旧 `dist` 与旧依赖：

```bash
set -euo pipefail
cd /opt/apps/dianzi51-admin
STAMP=$(date +%Y%m%dT%H%M%S)

pm2 stop dianzi51-admin
mv dist "dist.failed.${STAMP}"
mv dist.bak.20260731T152520 dist
mv node_modules "node_modules.failed.${STAMP}"
mv node_modules.bak.20260731T152520 node_modules
pm2 start ecosystem.config.cjs --only dianzi51-admin --update-env
pm2 save

nginx -t
curl -f http://127.0.0.1:3001/
curl -f http://47.97.108.147/admin/
```

如需恢复完整源码和 Nginx 配置，应使用预部署备份目录中的归档，并在执行前再次备份当前目录。生产数据库本次没有执行 schema 迁移或业务数据写入，因此无需数据库回滚。
