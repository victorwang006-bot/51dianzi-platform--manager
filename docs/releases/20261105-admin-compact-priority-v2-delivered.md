## 本轮五项修改

1. **渠道页头紧凑化**：标题、平铺/按渠道切换、上传操作合并，桌面页头约60px，窄屏自然换行，不再保留大块空白。
2. **员工管理**：删除列表中的所属团队列，实际团队关系与权限设置保留。新增删除用户入口，采用永久归档和访问关闭，历史客户、库存、创建人及业务记录不物理删除。正常列表隐藏，可查看已删除。删除提示为：**“删除后无法访问后台，历史数据保留。”**
3. **渠道筛选和数量排序**：增加行业筛选，支持全部行业、具体行业、未设置；与原来源、型号、品牌、批次条件组合。数量列正常状态也显示排序标识，点击降序、升序、默认循环，服务端按授权数据排序后分页。
4. **重点客户标星**：删除顶部和客户行中的“替员工标星”入口，直接点击公司名称后的星星。组长对合法员工客户操作同一负责人的重点状态，标星不改负责人，普通员工不获得额外代操作权限。
5. **客户返回记忆**：客户详情返回和浏览器返回保留原查询范围、筛选、页码、更多筛选展开、滚动位置与原客户定位；只有当前授权数据真正加载后恢复。账号、企业切换或撤权不会复用旧私有列表。

## 删除用户的保留边界

删除关闭后台访问，仅撤销其当前企业资格，不物理删除主站用户身份或历史业务。若该员工仍有需交接的真实业务、活跃任务或无法核验的遗留责任，先提示处理，不虚报删除成功。删除自己、企业所有者、最后有效超管及不合法跨企业操作会被阻止。跨服务异常保留原请求和待处理状态，可安全重试，不丢历史。

本任务未在生产环境创建、删除、标星、转派测试员工/客户/库存，也未执行真实员工删除。
