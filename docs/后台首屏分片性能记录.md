本记录固定后台首屏优化后的**根路径生产构建入口**大小，便于后续变更复核。比较口径是 Vite 生成的 `index.html` 所引用的唯一 `assets/index-*.js` 文件的**未压缩字节数**；该口径不将登录后才按需下载的路由块合并进首包。

| 指标 | 优化前基线 | 优化后测量值 | 变化 |
| --- | ---: | ---: | ---: |
| 根路径入口文件 | `index-CVNF81wm.js` | `index-v942yb2y.js` | 哈希随构建变化 |
| 入口原始大小 | 1,229,370 bytes | 427,276 bytes | **-802,094 bytes（-65.24%）** |
| 优化后 gzip -9 大小 | — | 131,125 bytes | 仅作当前制品参考 |

测量日期为 **2026-09-12**。基线是开始本次路由分片前工作目录中 `dist/public/assets/index-CVNF81wm.js` 的 `stat -c '%s'` 结果；优化后数值来自完成本次变更后执行 `pnpm build` 的根路径制品。两者均使用同一入口文件口径，因此变化值可直接复算为 `427276 - 1229370 = -802094`。

## 复核方法

在仓库根目录完成根路径构建后，使用下列命令定位 `index.html` 的入口，而不是依赖会变化的内容哈希文件名：

```bash
pnpm build
index=dist/public/index.html
entry=$(grep -oE 'src="/assets/index-[^"]+\.js"' "$index" \
  | sed -E 's/^src="(.*)"$/dist\/public\1/')
stat -c '%n %s bytes' "$entry"
gzip -9c "$entry" | wc -c
```

随后运行 `pnpm verify:subdomain-build`，确认该根路径制品仍只引用 `/assets/` 和 `/api/trpc`，没有混入旧 `/admin/` 基路径。

## 分片边界说明

入口文件只保留认证、路由、共享 UI 与动态导入表。`Login`、`Materials`、`Merchants`、`MerchantDetail`、`Messages`、`PortalUsers`、`Admins`、`Orders`、`Profile`、`ExceptionLogs`、`Reviews`、`Analytics`、`Forbidden`、`NotFound` 与受保护的 `DashboardLayout` 都生成独立构建块。未登录会停留在轻量认证壳和登录路由；只有认证成功后的路由匹配，或已授权侧边栏项目的指针/键盘意图，才会请求相应后台块。预取计数硬限制为两个，避免掠过菜单时下载整个后台。

本记录反映**首入口传输体积**，不是完整后台功能的总下载量。首次进入某个已授权页面仍会下载该页面及其必要共享块；例如图表模块保持在 `Analytics` 异步块中，以免进入登录页或普通后台页面时被下载。
