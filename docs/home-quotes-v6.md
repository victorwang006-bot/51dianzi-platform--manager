# 首页、渠道库存下载与多方案报价

版本：20261103-home-quotes-download-v6，显示时间统一北京时间。

渠道档案每行可下载该渠道全部本人授权库存（不是当前分页）。导出仍实时检查真实业务绑定、企业、本人负责人及渠道/库存模块权限；不包含联系人和私有备注。Excel保留料号、Date Code文本与精确价格；超10,000条整单提示，不截断为成功。主体或权限变化后，旧异步结果不得触发保存。团队默认共享与来源查看规则沿用v5，不扩大导出权限。

公开首页推荐模块提前挂载，以实际卡片相同尺寸静态占位；专属公开查询缓存和后台刷新保留已有内容。公开数据白名单和原卡片跳转不变，不修改全局查询策略。

业务工作台二级导航：渠道库存直达；客户与销售、库存管理、采购管理点击下拉；公司信息直达。权限过滤、商户上下文、历史别名及路由高亮不变，支持键盘与外部点击关闭。

同一需求行可给出独立数量、含税单价、交期和备注的多个报价方案，物料展示一次。历史记录按轮次保存，默认方案1兼容旧记录；旧客户端不明确方案号时不得覆盖或歧义采用多方案。采购仅采用每个需求行选中的一个方案，不累加全部备选。

采购候选汇总和采购单快照关联均须同时匹配审计轮次、需求行ID、采用方案号alternateNo；否则未采用备选会重复计量或计价。已建采购单保持其采用轮次的数量和价格，不随新报价覆盖。

上线需独立审批最小兼容DDL：三个既有报价明细表新增alternateNo INT NOT NULL DEFAULT 1；current/audit唯一键加入方案号；acceptance保留(acceptanceId,demandItemId)唯一。不重跑有历史回填的旧全量迁移，不重写历史团队、共享、岗位或ERP授权。前置短事务写入围栏与七表旧字段全量哈希保证历史内容不变。UI/API发布不得执行DDL；先前台完整API验收，再发布后台新界面/API。回滚只恢复目标界面/API，不还原数据库或后续用户操作。
