# 渠道团队库存 v5

版本：`20261103-channel-team-v5`。本轮为真实后端和界面增量，不是仅静态改版。

## 功能与权限

后台根入口及无显式目标的登录默认进入渠道库存；合法业务深链保留。原物料运营页面改用 `/materials`，仍保留原权限门禁。

渠道库存采用统一本人及当前有效同团队共享列表，取消“本人库存／团队共享”二级页签。将来用户新建库存时，在原事务内登记记录归属、建立默认团队共享并写审计。无有效团队时拒绝创建；历史未共享记录不自动共享，重放创建请求也不能复活已撤销的共享。

“渠道来源”替代列表中的私有备注列。本人及当前同团队组长可见来源；其他队员显示“无权查看”，服务端返回无来源数据的白名单 DTO。普通队员的来源筛选禁用，伪造来源筛选参数由服务端拒绝；组长的选项仅包含其可见库存的来源名称和标识，不开放联系人档案。组长可看来源，不因此获得其他队员库存的编辑或私有备注权限。

共享仍需要有效企业成员、ERP 库存权限及库存模块读权限。显式共享不被旧“仅本人范围”误挡，但共享者撤权、调组、离组重入或归属快照不匹配均使旧共享失效。非本人行只读；私有备注仅在本人详情编辑流程读取和维护。

可供数量及 Date Code 使用表头三态排序：默认、升序、降序。服务端排序先于分页；空值和未知批次置底，并以记录 ID 稳定兜底。Date Code 保留原始内容，不按更新时间替代。

## 安全与兼容

保留原单条／表格上传、请求幂等标识、详情版本 CAS、Excel 长数字型号保护。慢速详情响应在切页、新建、批量上传或关闭编辑会话后失效，不覆盖新草稿。新增接口为固定只读 `channelInventory.listTeamMaterials`、`channelInventory.listTeamSourceOptions`；后台继续使用真实绑定业务员工身份，不接受浏览器指定任意上游方法。

本轮不运行数据库迁移、角色初始化或历史共享回填，不修改既有团队／模块授权行。正式发布需使用独立完整源码 API 控制器，并保留原全部文件、环境、进程、Nginx、工作进程和回滚保护；不能使用旧纯静态控制器或声称 API 字节不变。
