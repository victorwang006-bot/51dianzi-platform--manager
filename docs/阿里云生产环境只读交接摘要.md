## 强制安全边界

生产 ECS、线上应用和生产 MySQL 在本次开发阶段均为**只读来源**。不得直接修改代码、执行 DDL/DML、重启 PM2/Nginx/MySQL、替换实例密钥、重置密码或改变安全组。开发数据应使用 `mysqldump --single-transaction --default-character-set=utf8mb4 dianzi51_admin` 从生产只读导出，然后导入 Manus 的隔离开发数据库。

## 当前 SSH 诊断事实

附件中的 PEM 私钥可以被 OpenSSH 正常解析，目标 `8.154.34.152:22` 可达，远端同时允许 `publickey,password`。目标主机返回的首次记录指纹如下：

| 算法 | SHA256 指纹 |
|---|---|
| RSA | `SHA256:MhvWOL8a50g0X1o55ePvoYrsf/qYOAykMyO5GsjuejQ` |
| ECDSA | `SHA256:1TV8EBNtXliAyRhE/7pf8M3Wut2aOEYXzJ5VEfF2vnU` |
| ED25519 | `SHA256:NxIg8jbMPY6JsH75rkWg5YUZWkt5le9+ugnwHuwU4GE` |

当前失败发生在服务器拒绝公钥认证，而不是私钥解析、网络连通或主机密钥校验阶段。下一步应通过阿里云只读 API 核对实例实际绑定的密钥对名称及公钥指纹，再判断登录用户名、绑定关系或 sshd 策略。

## 密钥拒绝根因（2026-08-03 已确认）

通过阿里云 ECS 官方只读接口 `DescribeInstanceAttribute`、`DescribeInstances` 和 `DescribeKeyPairs` 核验后，实例 `i-bp1dt09wlj7cm6dg49zr` 处于 `Running`，公网 IP、Ubuntu 22.04、4 核与 8 GB 内存均和交接资料一致，但实例返回的 `KeyPairName` 为空；当前账号在 `cn-hangzhou` 也未查询到名为 `zhijie_manager` 的云端密钥对。

附件私钥本身完整有效，其本地 MD5 公钥指纹为 `7a:c7:8d:c2:69:62:56:0d:32:d6:b3:dd:8b:ab:32:12`，与附件中紧邻 `zhijie_manager` 记录的无分隔符指纹 `7ac78dc26962560d32d6b3dd8bab3212` 完全一致。因此，**私钥文件正确，但该公钥当前既未作为 ECS 控制面密钥对绑定到目标实例，也未存在于服务器允许登录用户的 `authorized_keys` 中**。这解释了为什么 22 端口可达、私钥可解析，而服务端仍返回 `Permission denied (publickey,password)`。

在既定“生产只读、禁止重启或改动”约束下，本任务不会调用 `AttachKeyPair`、重置密码、修改 `authorized_keys` 或重启实例。要继续只读导出，需由用户提供当前有效的 SSH 登录凭据，或由服务器管理员在维护窗口恢复该公钥的授权。
