# 页面与金额展示知识点

## 页面保持简洁

不新增无必要的说明、注释、营销或统计口径文字。用户要求删除的说明不换一种说法放回页面。只保留功能名称、必要的真实业务状态，以及权限、错误和异常提示；已实现的精简设计不能被旧发布包还原。

## 个人中心金额展示

销售额、回款、未回款差额、提成等金额统一使用千分位和两位小数；订单笔数保持整数。显示层复用精确十进制字符串格式化，不用二进制浮点重新计算财务数据。

展示精度不等于计算精度。不得为了保留两位小数而修改数据库金额、税务口径、计提规则、收款记录、订单归属或权限。未知金额保持未知，不能显示为零，也不能把预计或可核实金额标成实际已发放。

规则版本、来源和核验细节在确有需要的详情或按需帮助中提供，不恢复主视图的冗余说明。
