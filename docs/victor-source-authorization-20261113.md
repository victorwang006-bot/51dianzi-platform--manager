# 渠道来源授权修复

用户于2026-11-13要求完成分享任务中的渠道来源修复。沿用已建立的智捷团队1及当前员工绑定，不新建或迁移团队，不修改权限、负责人、渠道分配或库存记录。

后台在现有管理员事务和业务授权栅栏内重新核验真实 active super_admin、会话版本、官方库存读取资格及员工绑定，只为该实际员工签发业务团队组长来源读取证明。普通官方团队组长仍使用当前官方团队员工名单，普通员工不获得新增证明。

生产发布只针对当前实际两个后端运行包的授权函数及签名协议表达式，精确基线比对、备份和原子替换，保留HTML、静态资源、Nginx、进程路径与环境及其他worker。
